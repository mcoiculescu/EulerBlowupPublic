# Lean coverage of the frozen paper

This ledger follows the manuscripts at `torus-paper-freeze-2026-11-18`.
It lists the 35 numbered assertions in the main paper and the three
numbered assertions in the auxiliary note. Remark 1.2 has no TeX label.
The unnumbered schedule formulas are recorded with the proof of
Lemma 1.3 in the [Appendix C correspondence](blueprint.md#appendix-c-and-the-parameter-estimates).

- **Verified** means the listed declarations together establish the
  stated assertion with its original hypotheses and quantifiers.
- **Partial** records the Lean results and the outstanding implication
  or the restricted domain.
- **Pending** records a proof or statement check in progress.

From `formalization/lean`, run the coverage check after building the
library.

```sh
lake env lean -DautoImplicit=false -DrelaxedAutoImplicit=false -DwarningAsError=true VerifyPaper.lean
```

The check requires one ledger row for every frozen assertion. It checks
the linked TeX environment and label and verifies that each declaration
in a Verified row is an imported theorem with only the three standard
axioms used by the project. Set
`TORUS_PAPER_REQUIRE_COMPLETE=1` to require all rows to be
Verified. The check also requires the unconditional auxiliary theorem
when either terminal-extension assertion is marked Verified.
